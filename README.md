# Tunely
A Spotify-style music player (static web app). All bundled music (`audio/`) was procedurally generated by code for this project and is released under CC0. Not affiliated with Spotify.

## Music sources
- **iTunes Search API** – 30-second previews.
- **Audius** – full-length tracks streamed from the Audius network.
- **Internet Archive** – full-length public-domain / openly licensed audio.
- **Openverse** (`api.openverse.org`, no key) – full-length Creative Commons music (mostly Jamendo, highest-quality file offered). Each track shows its creator and CC license with a link to the original page in the player's links area. Licenses vary (many are NC/ND): fine for personal listening, not for commercial reuse or redistribution of modified versions.
